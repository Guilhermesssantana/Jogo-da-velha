# Jogo da Velha

Este projeto é uma versão moderna do clássico jogo da velha, desenvolvida em Python com a biblioteca `pygame`.

## Objetivo

Criar uma interface visualmente agradável e funcional para praticar lógica de programação, manipulação de eventos e desenvolvimento de jogos em Python.

## Funcionalidades

- tabuleiro 3x3
- alternância entre jogadores X e O
- verificação automática de vitória
- detecção de empate
- reinício rápido da partida
- visual com tema escuro e moderno

## Requisitos

- Python 3
- biblioteca `pygame`

## Como instalar

```bash
pip install pygame
```

## Como executar

```bash
cd /home/gui/Documentos/repoProject
python3 jogo_da_velha.py
```
